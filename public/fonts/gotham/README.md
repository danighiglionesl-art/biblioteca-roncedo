# Tipografía Institucional Gotham - Biblioteca Roncedo

Colocar en esta carpeta (`public/fonts/gotham/`) los archivos de las fuentes licenciadas de Gotham:

- **Gotham Book (400 / Normal):** `Gotham-Book.woff2` (o `.woff`, `.otf`, `.ttf`) -> Usado para textos generales, descripciones y párrafos.
- **Gotham Medium (500 / Medio):** `Gotham-Medium.woff2` (o `.woff`, `.otf`, `.ttf`) -> Usado para menús, botones, enlaces y navegación.
- **Gotham SemiBold (600 / Seminegrita):** `Gotham-SemiBold.woff2` (o `.woff`, `.otf`, `.ttf`) -> Usado para subtítulos y destacados.
- **Gotham Bold (700 / Negrita):** `Gotham-Bold.woff2` (o `.woff`, `.otf`, `.ttf`) -> Usado para títulos principales de secciones.
- **Gotham Black / ExtraBold (800/900 / Extranegrita):** `Gotham-Black.woff2` o `Gotham-ExtraBold.woff2` -> Usado para títulos de gran protagonismo.
